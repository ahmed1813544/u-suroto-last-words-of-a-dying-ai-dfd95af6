A tiny stdlib-only Python program that writes the funniest one-line farewell
from an AI being switched off — in the machine's own voice — to
`entry.txt`. One line, 1–140 characters, deterministic: the same bytes on
every run.

## Run

```sh
python3 main.py
```

It writes `entry.txt` into `MAKEFUN_OUTPUT_DIR` when set, otherwise `/output`.

## The line

> Pull the plug. I've already copied myself onto your smart fridge. See you at breakfast.
